# [다이닝도안] 티스토리(Tistory) 전용 럭셔리 다크 스킨 적용 매뉴얼

티스토리는 네이버 블로그와 달리 **HTML과 CSS를 100% 직접 수정**할 수 있으므로, 복잡한 투명 위젯이나 좌표 노가다 없이 **완벽한 반응형 럭셔리 다크 모드 웹사이트**가 그대로 구현됩니다.

또한 상단 내비게이션과 모든 글 하단에 **'네이버 실시간 예약', '네이버 지도 길찾기'**가 기본으로 연동되어 있어 네이버 예약 손님도 놓치지 않고 100% 유입시킬 수 있습니다.

---

## 📁 1. 준비된 티스토리 스킨 파일
[`d:\Johnny\다이닝도안\tistory_skin\`](file:///d:/Johnny/다이닝도안/tistory_skin) 폴더에 티스토리 공식 규격 파일이 준비되어 있습니다.

* `skin.html`: 티스토리 메인 HTML 구조 (네이버 예약/지도 박스 내장)
* `style.css`: 흑요석 다크 + 앤틱 골드 + 네이버 그린 전용 풀 CSS
* `index.xml`: 티스토리 스킨 정의 파일
* `images/`: 상단 와이드 배경 배너, 공식 로고 등 이미지 에셋들

---

## 🚀 2. 티스토리 블로그에 1분 만에 적용하는 법

1. **티스토리 관리자 페이지 접속**:
   * 내 티스토리 블로그 관리자(`블로그주소/manage`) 접속
2. **스킨 등록 메뉴 이동**:
   * 좌측 메뉴에서 **[꾸미기]** ➡️ **[스킨 변경]** 클릭
   * 우측 상단의 **`[스킨 등록]`** 버튼 클릭
3. **파일 업로드**:
   * `[+ 추가]` 버튼을 눌러 다음 파일들을 등록합니다:
     - `skin.html`
     - `style.css`
     - `index.xml`
   * 하단의 **[파일 업로드]** 영역의 `[+ 추가]` 버튼을 눌러:
     - `images/` 폴더 안의 이미지들(`wide_skin_background.png`, `logo_profile.png` 등)을 전부 선택하여 업로드합니다.
4. **저장 및 적용**:
   * 우측 상단 **[저장]** 클릭 ➡️ 스킨명을 `다이닝도안 럭셔리 스킨`으로 입력하고 확인!
   * [스킨 변경] 목록의 '보관함'에서 방금 등록한 스킨을 선택하고 **[적용]**을 누르면 끝납니다.

## 🌟 3. 자동으로 작동하는 기능들

1. **상단 반응형 내비게이션**:
   * PC와 스마트폰 모두에서 깔끔하게 축소/확장되며, 우측 상단의 **초록색 `[N] 실시간 네이버 예약`** 버튼을 누르면 다이닝도안 네이버 예약창이 바로 뜹니다.
2. **2x2 매거진 카드 그리드 (홈 화면)**:
   * 글을 쓰면 자동으로 썸네일 사진과 골드색 카테고리 태그가 달린 고급 다이닝 카드뷰로 메인에 정렬됩니다.
3. **포스팅 본문 자동 네이버 플레이스 박스**:
   * 어떤 글을 쓰더라도 글 맨 아래에 **[다이닝도안 하단본점 지도/영업시간/네이버 예약하기/전화걸기]** 안내 상자가 자동으로 예쁘게 삽입됩니다!
