## 🚀 2. 네이버 블로그 실제 기능 연동 세팅 순서

### [STEP 1] 투명 이미지 인터넷 주소(URL) 만들기 (1분 소요)
1. 내 블로그 **[글쓰기]**를 누릅니다.
2. [transparent_170x600.png](file:///d:/Johnny/다이닝도안/naver_blog_final_package/images/transparent_170x600.png) 이미지를 글 본문에 사진 첨부합니다.
3. 글 발행 시 공개 설정을 **[비공개]**로 체크하고 [발행]합니다.
4. 발행된 비공개 글에서 첨부된 투명 이미지 위에 마우스 우클릭 ➡️ **`[이미지 주소 복사]`**를 클릭합니다.
   *(복사된 주소 형태: `https://postfiles.pstatic.net/..../transparent_170x600.png`)*

---

### [STEP 2] 레이아웃 설정
1. 내 블로그 홈 우측 상단 **[내 메뉴]** ➡️ **[관리]** 클릭
2. **[꾸미기 설정]** 탭 ➡️ **[레이아웃·위젯 설정]** 클릭
3. 상단 레이아웃 목록 중 **와이드 1단 레이아웃** (상단 전체가 1칸으로 넓게 트인 모양) 선택
4. 우측 메뉴 형태 설정에서 **[타이틀] 체크 해제** (체크를 풀어야 상단 배너가 홈페이지처럼 시원하게 보입니다).

---

### [STEP 3] 상단 와이드 스킨(배경) 등록
1. 좌측 메뉴에서 **[세부 디자인 설정]** (리모콘) 클릭
2. 리모콘 창에서 **[스킨배경]** 클릭 ➡️ **[직접등록]** 탭 클릭
3. `[파일 등록]` 버튼을 누르고 [wide_skin_background.png](file:///d:/Johnny/다이닝도안/naver_blog_final_package/images/wide_skin_background.png) 선택 후 등록
4. 리모콘 우측 하단 **[적용]** 클릭!
