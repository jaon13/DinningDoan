# [다이닝도안] 네이버 블로그 레이아웃 & 위젯 아키텍처 완벽 실전 가이드

> **핵심 원리**: 네이버 블로그는 CSS 파일 직접 수정이 불가능합니다.  
> 따라서 **네이버의 `[레이아웃·위젯 설정]` GUI 시스템을 CSS의 Flexbox/Grid처럼 활용하여 구조를 잡고, `[투명 위젯]`으로 클릭 영역(Interactive Hotspot)을 생성**합니다.

---

## 🏛️ 1. 네이버 블로그 레이아웃의 CSS 대체 원리 (Deep Dive)

일반 웹 개발과 네이버 블로그 설정의 1:1 매핑 구조를 이해하면 원하는 대로 레이아웃을 통제할 수 있습니다.

```text
┌───────────────────────────────────────────────────────────────────────────────────┐
│                    네이버 블로그 전체 화면 (스킨 배경 이미지 영역)                     │
│               background: url('wide_skin_background.png') center top              │
│                                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────────┐  │
│  │                상단 배너 영역 (높이: 600px 빈 공간 확보 구역)                 │  │
│  │    [위젯 1]        [위젯 2]        [위젯 3]        [위젯 4]        [위젯 5]    │  │
│  │   (가로 170px)    (가로 170px)    (가로 170px)    (가로 170px)    (가로 170px) │  │
│  │    시그니처메뉴       매장오시는길     실시간예약(★)     인스타그램        전화문의   │  │
│  │    width: 170px; height: 600px; opacity: 0; display: flex; (클릭 감지 영역)   │  │
│  └─────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────────┐  │
│  │                      블로그 메인 본문 구역 (포스트/프롤로그)                     │  │
│  │                 (상단 위젯에 의해 저절로 600px 아래로 밀려나 위치함)             │  │
│  │                   margin-top: 600px 효과 / 2x2 카드형 매거진 그리드             │  │
│  └─────────────────────────────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### 1) 높이와 여백의 통제 (`padding-top` / `margin-top` 대체)
* 일반 웹: `header { height: 600px; }`
* 네이버 블로그: 본문 상단에 **세로 600px짜리 투명 이미지 위젯**을 가로로 배치합니다. 브라우저는 이 600px 공간을 차지하는 투명 블록을 렌더링하기 위해 **글 본문 영역을 저절로 600px 아래로 밀어냅니다.**

### 2) 가로 폭과 정렬의 통제 (`width`, `justify-content` 대체)
* 네이버 위젯의 **공식 고정 규격은 가로 최대 170px**입니다.
* 네이버 와이드 1단 레이아웃의 상단 중앙 영역은 **가로 총 5개(170px × 5 = 850px, 여백 포함 약 966px)**의 위젯을 가로 1열로 수평 정렬(Flex Row)할 수 있습니다.

## 🛠️ 2. 단계별 초정밀 세팅 절차

### [STEP 1] 투명 이미지 생성 및 네이버 클라우드 주소 추출
위젯 코드가 투명 영역을 잡으려면 170x600px 크기의 투명 PNG 파일이 네이버 서버에 올라가 있어야 합니다.

1. 파일 준비: [`d:\Johnny\다이닝도안\naver_blog_final_package\images\transparent_170x600.png`](file:///d:/Johnny/다이닝도안/naver_blog_final_package/images/transparent_170x600.png)
2. 내 블로그 접속 ➡️ 상단 **[글쓰기]** 클릭
3. 글쓰기 에디터 상단의 **[사진]** 아이콘 클릭 ➡️ `transparent_170x600.png` 파일 선택하여 본문에 첨부
4. 우측 상단 **[발행]** 버튼 클릭:
   * **공개설정: [비공개]** 체크 (손님에게 보이지 않게 보관용으로 발행)
   * 카테고리: 아무 카테고리나 무관
   * 하단 [발행] 클릭
5. 발행된 비공개 글에서 첨부된 투명 이미지 위에서 **마우스 우클릭** ➡️ **`[이미지 주소 복사]`** 클릭
   * 클립보드에 복사된 주소 예시:
     `https://postfiles.pstatic.net/MjAy.../transparent_170x600.png?type=w966`
   * 이 주소가 앞으로 모든 위젯의 `src`에 들어가는 **[투명 이미지 주소]**입니다.

---

### [STEP 2] 레이아웃 설정 (Grid 구조 정의)
1. 블로그 메인 화면 우측 상단 **[내 메뉴]** ➡️ **[관리]** 클릭
2. 상단 메뉴 중 **[꾸미기 설정]** 탭 ➡️ 좌측 메뉴의 **[레이아웃·위젯 설정]** 클릭
3. **레이아웃 형태 선택**:
   * 상단에 12개의 사각형 그리드 레이아웃 형태가 있습니다.
   * **가장 우측 상단에 있는 [와이드 1단 레이아웃]**(사이드바 없이 상단과 본문이 시원하게 가로 100%로 트여 있는 모양)을 선택합니다.
4. **메뉴 사용 설정 (체크박스 제어 - 중요 ⭐)**:
   * `[타이틀]` ➡️ **체크 해제 (OFF)**: 체크가 되어 있으면 네이버 기본 타이틀 바가 자리를 차지해 배너 디자인이 깨집니다.
   * `[메뉴형태]` ➡️ 기본형 유지
   * `[블로그 정보]`, `[카테고리]`, `[이웃목록]` 등은 본문 아래쪽이나 우측 하단으로 자유롭게 드래그해 배치합니다.

---

### [STEP 3] 상단 와이드 스킨 등록 (배경 CSS 대체)
1. 좌측 메뉴에서 **[세부 디자인 설정]** 클릭 (화면에 '리모콘' 도구창이 나타납니다).
2. 리모콘 메뉴에서 **[스킨배경]** 클릭 ➡️ **[직접등록]** 탭 선택
3. `[상단영역]` 또는 `[스킨배경]`의 **`[파일 등록]`** 버튼 클릭
4. [`d:\Johnny\다이닝도안\naver_blog_final_package\images\wide_skin_background.png`](file:///d:/Johnny/다이닝도안/naver_blog_final_package/images/wide_skin_background.png) 선택 후 등록
5. 패턴 설정: **[반복 안함]**, 위치: **[가운데 상단 (Center Top)]**
6. 리모콘 우측 하단 **[적용]** 클릭

### [STEP 4] 5대 실제 기능 연동 위젯 생성 (Interactive Code)
`[레이아웃·위젯 설정]` 화면 우측 하단의 **`[+ 위젯 직접등록]`** 버튼을 5번 눌러 각각 추가합니다.

```html

  <img src="https://투명_이미지_주소" width="170" height="600" border="0" style="display:block; cursor:pointer;" alt="다이닝도안 메뉴판">
```

### [STEP 5] 레이아웃 창에서 위젯 물리적 드래그 정렬 (Flex Row 배치)
등록이 완료되면 우측 `위젯 사용 설정` 목록 맨 아래에 내가 등록한 5개의 위젯 체크박스가 생깁니다.

1. 5개 위젯(`W1_메뉴판`, `W2_오시는길`, `W3_네이버예약`, `W4_인스타그램`, `W5_전화문의`)에 모두 **체크**합니다.
2. 좌측 미리보기 배치 화면에서 마우스로 드래그하여 **메인 상단 영역에 가로로 나란히 1열**로 배치합니다:
   ```text
   [ W1_메뉴판 ] [ W2_오시는길 ] [ W3_네이버예약 ] [ W4_인스타그램 ] [ W5_전화문의 ]
   ```
3. 화면 맨 아래의 **[적용]** 버튼을 클릭합니다.
